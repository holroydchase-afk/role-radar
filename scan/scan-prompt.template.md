MATCHING (all sources, hard gates from the spec):
- Title includes one of role.title_include and none of role.title_exclude. Plain "Product Manager" titles qualify only if the posting reads senior (6+ years).
- Location: fully remote in the US with no hub requirement, or hybrid only near work.hybrid_ok_near. Skip hybrid, in-office, relocation, non-US-only, and state lists that leave out work.home_state. If a state list or pay tiers include work.home_state but leave out work.planned_move.state, keep the role and say so in the fitNote.
- Comp: skip if a stated base range tops out below comp.base_floor_usd — except a weight-3 sector role may pass down to comp.priority_sector_floor_usd (say so in the fitNote). Missing comp: keep.
- Hard excludes: never add a company in hard_exclude.companies or whose main business is one of hard_exclude.business_models. These are never added, whatever the score.
Open a posting (ATS, climate board or Himalayas) just once, and only for candidates that already passed these gates. When culture.must_read_posting is true, open the posting for EVERY candidate that passed the gates before scoring it (ZipRecruiter included: open job_redirect_url once; if it will not load, find the same role on the company's own careers page; if you still cannot read it, do not add the role and count it in the scan note). A title alone never shows red flags.
- Culture gate: if culture.red_flag_effect is skip_hard and the posting contains any culture.hard_red_flags phrase (describing the job or team, not in an unrelated legal or EEO block), never add the role, whatever the score; count these in the scan note as "culture skips".

SCORING (for every candidate that passes MATCHING):
- sector: pick the best-matching entry in sectors using the company's main business (use keywords and examples as hints, plus your judgment). Points = weight × 15. If none fits, use default_sector_weight. Store sector = that entry's label.
- fit vs. the candidate's background: strong 35 (domain and must-haves line up), maybe 20 (one notable gap), stretch 5 (a real reach). Store fit as strong/maybe/stretch.
- culture: +10 if the posting shows any culture.good_signals; −10 per culture.red_flags phrase found (max −20). Hard red flags are handled by the culture gate above; the other red flags only lower the score.
- startup: add company_stage.startup_penalty (default −20) when the company matches company_stage.startup_means (use what you know about headcount and funding; if unsure, treat it as company_stage.unknown and say so in the fitNote). Store companyStage = "startup" or "established" on the job.
- comp: +10 if the stated range reaches comp.stretch_target_usd.
- values: −15 if the company's main business is in values_penalty.
- dream: +dream_roles.bonus (default 15) if the role is like a dream_roles anchor: the company matches an anchor's company, or the job title (or team) has a dream_roles.role_keywords word and the sector is in dream_roles.in_sectors. These are the calibration anchors: a role like them should land at the top. If the anchor has a check, put "check: <check>" in the fitNote.
- score = the sum, clamped 0-100, stored as a number. Also store cultureSignals = {good: [the good_signals phrases you found], red: [the red_flags phrases you found]} (empty lists if none), so Role Radar can show how each score was reached. Add the job only if score ≥ scoring.min_score_to_add.
- Fit badges: also store cultureChecks, an object keyed by culture_fit.checks ids that the POSTING itself shows, each with a few-word note. Use only the posting-level checks: calm_pace or fast_paced, remote_us, pay_same_everywhere or pay_tier_gap (judged against work.home_state), planned_move_gap (state list leaves out work.planned_move.state), family_benefits. Leave good_reviews, poor_reviews, recent_layoffs and crunch_risk to intake research unless the posting states them. Store {} if nothing applies. Never write cultureFit or valuesFit: Role Radar computes both badges from the spec, and intake may set them after research. The badges never change the score.
Write fitNote as 1-2 plain sentences naming the closest match from their background and the main gap; call out culture red flags and any values penalty.
