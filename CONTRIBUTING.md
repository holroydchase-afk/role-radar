# Contributing to Role Radar

Thanks for taking a look. This is a one-person project, so the process is light.

- **Found a bug or have an idea?** Open an issue using the template. Say what you expected and what happened.
- **Want to change something?** Open an issue first for anything bigger than a typo, then send a small pull request that does one thing.
- **Before you push:** run `npm test` and `npm run check:private`, and update `HANDOFF.md` if your change moves the work.
- **Keep it public-safe.** This repo is public and sits next to a real job search. Never commit real recruiter names, emails, application data or Gmail content. Use the labeled demo data in `demo/`.
- **Be kind.** Everyone here follows the [Code of Conduct](CODE_OF_CONDUCT.md).

Security problems and accidental leaks go through [SECURITY.md](SECURITY.md), not a public issue.
